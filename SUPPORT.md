# Support

## Where to ask

- For reproducible bugs or focused proposals, open an issue in the [GitHub repository](https://github.com/Brajesh31/Bulk-Mail-Project/issues).
- For setup questions, read [Installation](docs/installation.md) and [Troubleshooting](docs/troubleshooting.md).
- For vulnerabilities, leaked credentials, or email abuse, follow [SECURITY.md](SECURITY.md) and report privately.
- For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact the maintainer through [@brajesh31](https://github.com/brajesh31).

## Include useful details

Share the affected app (backend or frontend), Node.js version, command, reproduction steps, and relevant redacted logs. Never include passwords, MongoDB connection strings, message content, recipient lists, or account tokens in a public report.

## Project scope

This is an individual project prototype, not a supported email delivery service. It has no uptime, delivery, response-time, or abuse-monitoring commitment. Do not use it to send mail to people who have not explicitly agreed to receive it.
